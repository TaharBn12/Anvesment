# 💻 تشغيل البوت على الكمبيوتر

> على الكمبيوتر الموضوع سهل: Node يعمل أصلياً بدون أي محاكاة.
> كل اللي تحتاجه **Node 22.5 أو أحدث** — وهذا الشرط الوحيد المهم.

---

## 🖱️ الطريقة الأسهل: مثبّت بنقرة واحدة (Windows)

**ما تحتاج تكتب أي أمر ولا تفتح cmd.** الملف يعمل كل شيء لوحده.

### 1️⃣ حمّل المثبّت

افتح هذا الرابط في المتصفح، واضغط يمين ← **حفظ باسم** / Save as:

```
https://raw.githubusercontent.com/TaharBn12/Anvesment/main/scripts/install-windows.bat
```

### 2️⃣ شغّله

**انقر مرتين على `install-windows.bat`** — وخلاص ✅

المثبّت ينفّذ كل هذا تلقائياً:

| # | ما يفعله |
|---|---|
| 1 | يتحقق من Node.js — ولو ناقص **يفتح صفحة التحميل** ويشرحلك شنو تعمل |
| 2 | **يحمّل المشروع** من GitHub بنفسه |
| 3 | يفكّ الضغط في `C:\Users\اسمك\Anvesment` |
| 4 | يجهّز ملف `.env` و**يفتح Notepad** يسألك على التوكن |
| 5 | `npm install` |
| 6 | يشغّل البوت |

### 3️⃣ المرات القادمة

بعد أول مرة صار عندك مجلد `C:\Users\اسمك\Anvesment`.
لتشغيل البوت لاحقاً: ادخله ← مجلد `scripts` ← **انقر مرتين على `start.bat`**

> 💡 لو المتصفح حذف الملف `.bat` أو غيّر اسمه، جرّب الرابط مرة أخرى
> وتأكد أن الاسم ينتهي بـ `.bat` مو `.bat.txt`

## ⌨️ الطريقة اليدوية (كل الأنظمة)

### 1️⃣ حمّل المشروع

**بـ git:**
```bash
git clone https://github.com/TaharBn12/Anvesment.git
cd Anvesment
```

**أو بدون git:** من صفحة المستودع اضغط الزر الأخضر **`<> Code`** ← **Download ZIP**،
ثم فُكّ الضغط وادخل المجلد.

> ✅ **الآن زر Download ZIP يعطي الكود الكامل** — الكود مدموج في فرع `main`.

### 2️⃣ جهّز ملف الإعدادات

انسخ الملف الجاهز إلى `.env`:

```bash
# Windows (PowerShell / cmd)
copy .env.example .env

# Mac / Linux
cp .env.example .env
```

افتح `.env` بأي محرر (Notepad على ويندوز) وضع توكنك من [@BotFather](https://t.me/BotFather)
في سطر `BOT_TOKEN=`.

> 🔐 **لا ترفع ملف `.env` على GitHub أبداً** — هو مستثنى تلقائياً في `.gitignore`،
> لكن ما تشاركه مع أحد لأن التوكن يعطي تحكماً كاملاً بالبوت.

### 3️⃣ ثبّت الحزم وشغّل

```bash
npm install
npm start
```

**لازم تشوف هذي الأسطر:**

```
✅ قاعدة البيانات جاهزة: .../data/bot.db
✅ خادم الإشعارات يعمل على المنفذ 3000
🚀 البوت يعمل (وضع polling)
```

افتح تلغرام → بوتك → `/start` 🎉

## ⚠️ متطلبات: Node 22.5+

قاعدة البيانات في هذا المشروع مبنية على `node:sqlite`، وهي **وُجدت في Node 22.5**.
لو ثبّيت Node أقدم، البوت ما يشتغل ويطلع خطأ غامض.

**كيف تعرف نسختك؟** افتح الطرفية واكتب:

```bash
node -v
```

| النتيجة | الحالة |
|---|---|
| `v22.5.0` أو أعلى (22.x / 24.x / 26.x) | ✅ ممتاز، كمّل |
| `v20.x` أو أقل، أو `command not found` | ❌ ثبّت Node جديد |

**للتثبيت:** افتح [nodejs.org](https://nodejs.org) وحمّل النسخة التي عليها شارة **LTS**
(اضغط Next في كل الخطوات، لا تغيّر شيء). بعدها **أغلق الطرفية وافتح واحدة جديدة**
وتحقق بـ `node -v`.

## 👑 خلّ نفسك أدمن

1. من تلغرام أرسل `/id` للبوت → يعطيك رقماً مثل `123456789`
2. افتح `.env` وعدّل:
```env
ADMIN_IDS=123456789
```
3. أوقف البوت (`CTRL+C`) وشغّله مرة أخرى: `npm start`
4. أرسل `/admin` → تظهر لوحة التحكم 🎛️

## 🔔 الإيداع التلقائي الفوري (اختياري)

البوت يستقبل إشعارات NOWPayments على المنفذ **3000**. بدون إعداد، الإيداع يعمل
عبر المتابعة الدورية (تأخير دقيقة) — وهذا يكفي للتجربة.

للإيداع الفوري على الكمبيوتر، تحتاج رابطاً عاماً. أسهل طريقة [ngrok](https://ngrok.com):

```bash
ngrok http 3000
```

ينتج رابط مثل `https://a1b2.ngrok-free.app`، ثم:
1. ضعه في `.env`: `PUBLIC_URL=https://a1b2.ngrok-free.app`
2. في لوحة NOWPayments ← **Settings ← IPN** ضع:
   `https://a1b2.ngrok-free.app/webhooks/nowpayments`

## 🛑 أهم نقطة: البوت يموت مع الكمبيوتر

بوت تلغرام يحتاج يبقى **متصل 24 ساعة**. على الكمبيوتر:

| الموقف | النتيجة |
|---|---|
| أغلقت الطرفية | البوت يتوقف ❌ |
| الكمبيوتر نام / Sleep | البوت يتوقف ❌ |
| انقطاع الإنترنت أو الكهرباء | البوت يتوقف ❌ |
| أطفأت الكمبيوتر | البوت يتوقف ❌ |

**للتجربة والتعلّم:** هذا كافي تماماً، ولا بأس.

**للاستخدام الحقيقي مع مستخدمين ومبالغ:** انشر البوت على سيرفر —
👉 [دليل Koyeb المجاني](KOYEB_AR.md) (بدون أي طرفية، من المتصفح).

### إبقاء الكمبيوتر شغّالاً (Windows)
1. **الإعدادات ← النظام ← الطاقة والنوم**
2. حوّل **"Sleep"** إلى **"Never"**
3. خلّ الكمبيوتر موصولاً بالكهرباء

## 🆘 حل المشاكل

| الخطأ | المعنى | الحل |
|---|---|---|
| `npm error code ENOENT ... Could not read package.json` | أنت في المجلد الخطأ | افتح المجلد في File Explorer → شريط المسار → اكتب `cmd` → Enter |
| `node:sqlite is not available` / `ERR_UNKNOWN_BUILTIN_MODULE` | Node قديم | ثبّت Node 22.5+ من [nodejs.org](https://nodejs.org) |
| `'node' is not recognized` | Node غير مثبت أو ما فتحتش طرفية جديدة | ثبّته، ثم **أغلق الطرفية وافتح واحدة جديدة** |
| `ETELEGRAM: 401 Unauthorized` | التوكن خاطئ أو مُبطَل | راجع `BOT_TOKEN` في `.env` — أو خذ توكن جديد من @BotFather |
| السجل يقول `فشل الاتصال بتلغرام` باستمرار | التوكن خاطئ، أو النت قطع، أو تلغرام محجوب | راجع التوكن؛ لو استمر مع توكن صحيح فالشبكة تمنع الوصول لـ api.telegram.org |
| `ETELEGRAM: 409 Conflict` | نسخة ثانية من البوت تعمل | أقفل أي نافذة أخرى تشغّل البوت |
| `EADDRINUSE: port 3000` | المنفذ مشغول | أقفل البرنامج الآخر، أو غيّر `WEBHOOK_PORT=3001` في `.env` |
| البوت يرد ثم يتوقف | انتهت الجلسة أو الشبكة | راجع السجل؛ أعد `npm start` |
| فقدت الأرصدة بعد إعادة التثبيت | حذفت مجلد `data/` | لا تحذف `data/bot.db` أبداً — فيه كل شيء |
| `npm install` يفشل | شبكة أو صلاحيات | جرّب على شبكة أخرى، أو شغّل الطرفية كمسؤول (Run as Administrator) |
| `install-windows.bat` يُفتح كنص بدل ما ينفّذ | المتصفح حفظه `.txt` | غيّر الامتداد إلى `.bat` |
| فتح البوت ومكتوب `node:command not found` بعد التثبيت | Node ما اتسجّلش في PATH | أعد تشغيل الكمبيوتر، أو أعد تثبيت Node |

## 📁 شنو يصير في المجلد؟

```
Anvesment/
├── data/bot.db      ← قاعدة البيانات (أرصدة، عقود، سجل) — لا تحذفها!
├── .env             ← توكنك وإعداداتك — لا تشاركه
├── src/             ← كود البوت
├── scripts/
│   ├── install-windows.bat ← مثبّت بنقرة (أول مرة)
│   ├── start.bat           ← تشغيل سريع (بعدها)
│   └── setup.sh            ← تثبيت بأمر واحد على سيرفر
└── docs/            ← الأدلة العربية
```

> 💾 **نسخة احتياطية:** أرسل `/backup` للبوت (تحتاج `ADMIN_IDS`) فيحمّل ملف القاعدة.
> خُذه قبل أي تعديل على `.env` أو تحديث للكود.
