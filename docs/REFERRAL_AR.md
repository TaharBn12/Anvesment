# 🤝 نظام الإحالة — دليل كامل

نظام إحالة مدمج: كل مستخدم عنده **رابط خاص**، وكل صديق يسجّل عبر رابطه
ويعمل أول إيداع → تحصل على **20 دولار** في رصيدك تلقائياً.

---

## 📋 ملخص سريع

| | |
|---|---|
| **المكافأة** | 20$ لكل إحالة ناجحة (قابلة للتغيير) |
| **متى تُصرف** | عند **أول إيداع** للمستخدم المُحال |
| **عدد المرات** | مرة واحدة فقط لكل مستخدم |
| **الإحالة الذاتية** | مرفوضة تلقائياً |

---

## 👤 من جهة المستخدم

### 1) تجيب رابطك

من القائمة: **💼 محفظتي** → **🤝 رابط الإحالة**

```
🤝 نظام الإحالة

💰 اربح 20$ عن كل صديق يسجّل عبر رابطك ويعمل أول إيداع.

🔗 رابطك الخاص:
https://t.me/YourBot?start=ref_A1B2C3D4

👥 عدد المدعوين: 3
✅ مدعوّن أودعوا: 2
⏳ في الانتظار: 1
💵 إجمالي أرباحك من الإحالة: 40 $

📤 اضغط زر «مشاركة الرابط» بالأسفل وأرسله لأصدقائك.
```

تحت الرسالة زرّان:
- **📤 مشاركة الرابط** — يفتح قائمة مشاركة تلغرام (تختار صديق أو قروب)
- **🔗 فتح الرابط** — يفتح رابطك في المتصفح

### 2) يضغط صديقك على الرابط

يفتح المحادثة مع البوت مباشرة، ويشوف:

```
🎉 انضممت عبر رابط أحمد!

👋 مرحباً أحمد في بوت الاستثمار!
...
```

### 3) يعمل أول إيداع

لما يودع صديقك (أي مبلغ فوق الحد الأدنى) → توصلك رسالة:

```
🎉 مكافأة إحالة جديدة!

💰 حصلت على 20$ لانضمام مستخدم عبر رابطك.
👤 المستخدم: خالد

شارك رابطك أكثر لتربح أكثر 🔗
```

والمبلغ يكون أُضيف في رصيدك، ويظهر في سجل العمليات كـ **مكافأة إحالة**.

## ⚙️ من جهة المشغّل

### تغيير قيمة المكافأة

في ملف `.env`:

```env
REFERRAL_BONUS=20
```

غيّر الرقم لأي قيمة. **`0` = إيقاف النظام بالكامل** (ما تُصرف أي مكافأة).

### تغيير اسم البوت (اختياري)

رابط الإحالة يحتاج اسم مستخدم البوت. البوت يجيبه **تلقائياً** من تلغرام
عند التشغيل، فما تحتاج تضبط شي. لكن لو حاب تثبّته:

```env
BOT_USERNAME=YourBotName
```

بدون `@`.

## 🔒 قواعد الحماية

| القاعدة | التفصيل |
|---|---|
| **مرة واحدة لكل مستخدم** | المكافأة تُصرف عند أول إيداع فقط — الإيداعات التالية ما تضيف شي |
| **الإحالة الذاتية مرفوضة** | لو فتحت رابطك بنفسك، ما يُحتسب |
| **ربط دائم** | كل مستخدم مرتبط بمُحيل واحد مدى الحياة — ما يقدر يتبدّل |
| **يشترط إيداع** | التسجيل لوحده ما يكفي — يمنع الحسابات الوهمية |
| **الإضافة آمنة** | لو صُرفت المكافأة وفشل الإشعار، ما تتكرر عند إعادة المحاولة |

## 🧾 كيف تشوف الأرباح

**من جهة المستخدم:** 💼 محفظتي → 🧾 سجل العمليات → يظهر `مكافأة إحالة +20 $`

**من قاعدة البيانات:**

```sql
-- أرباح الإحالة لكل المستخدمين
SELECT user_id, COUNT(*) AS عدد, SUM(amount)/1000000.0 AS دولار
FROM transactions WHERE type = 'referral'
GROUP BY user_id ORDER BY دولار DESC;

-- من دعا من
SELECT referred_by, COUNT(*) AS المدعوّن
FROM users WHERE referred_by IS NOT NULL
GROUP BY referred_by;
```

## ❓ أسئلة شائعة

**س: صديقي سجّل عبر رابطك، متى يوصلني الفلوس؟**
ج: لحظة ما يعمل أول إيداع ناجح. التسجيل لوحده ما يكفي.

**س: صديقي سجّل قبل ما أشارك رابطي — يحتسب؟**
ج: للأسف لا. الارتباط يُسجّل لحظة التسجيل عبر الرابط فقط.

**س: غيرت `REFERRAL_BONUS` بعد ما صارت مكافآت — شنو يصير للقديم؟**
ج: القديم يبقى كما هو. القيمة الجديدة تُطبّق على المكافآت الجديدة فقط.

**س: أبغى المكافأة فورية عند التسجيل بدون إيداع؟**
ج: عدّل `payReferralBonus` في `src/services/referrals.js` واستدعِها
من `registerStartHandlers` بدل `creditDeposit` — لكن **ما ننصحك**،
النظام يصير قابل للاستغلال بحسابات وهمية.

**س: رابط الإحالة يظهر «تعذّر بناء الرابط»؟**
ج: معناها `BOT_USERNAME` فاضي وما نجحنا نجيب اسم البوت من تلغرام.
تأكد أن البوت يعمل (`/start` شغّال) ثم أعد فتح الصفحة.
