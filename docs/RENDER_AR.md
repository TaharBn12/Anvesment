# ☁️ دليل النشر على Render

> **قبل ما تبدأ، اقرأ هالملاحظة بصدق:**
> الخطة المجانية في Render **تفقد كل الملفات المحلية** — بما فيها قاعدة
> بيانات SQLite — عند كل إعادة تشغيل أو نشر. ومعناها لو استخدمتها مجاناً،
> **الأرصدة والعقود تُمسح**. الحلول الثلاثة في الأسفل.

## 1️⃣ طريقة Blueprint — نشر بضغطة واحدة

جهّزتُ لك ملف `render.yaml` يقرأه Render تلقائياً فيجهّز كل شيء.

### الخطوات (من متصفح هاتفك)

1. سجّل في [render.com](https://render.com) بحساب GitHub
2. من اللوحة: **New +** (أعلى اليمين) ← **Blueprint**
3. اختر المستودع `Anvesment` ← **Connect**
4. Render يقرأ `render.yaml` ويعرض الخدمة `investment-bot` ← اضغط **Apply**
5. بعد الإنشاء، ادخل **Environment** وأضف المتغيرات السرّية:

| المتغير | من أين |
|---|---|
| `BOT_TOKEN` | من [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | اتركه فارغاً الآن — شرحه بالأسفل |
| `NOWPAYMENTS_API_KEY` | لوحة NOWPayments ← Settings |
| `NOWPAYMENTS_IPN_SECRET` | لوحة NOWPayments ← Payments ← IPN |

6. اضغط **Save Changes** ← Render يعيد النشر تلقائياً
7. بعد دقيقتين، افتح الرابط: `https://investment-bot.onrender.com/health`

لازم تشوف: `{"ok":true,...}` ✅

## 2️⃣ طريقة يدوية (بدون Blueprint)

1. **New +** ← **Web Service**
2. اختر المستودع ← **Connect**
3. الإعدادات:

| الحقل | القيمة |
|---|---|
| **Name** | `investment-bot` |
| **Region** | Frankfurt (أقرب للجزائر) |
| **Branch** | `main` |
| **Runtime** | **Docker** |
| **Dockerfile Path** | `./Dockerfile` |
| **Plan** | Free |

4. **Advanced** ← أضف:
   - **Health Check Path**: `/health`
   - **Docker Command**: (اتركه فارغاً — Dockerfile يتكفّل)
5. **Environment Variables** — أضف نفس المتغيرات في الجدول أعلاه، **زائد**:

```env
SELF_PING_URL=https://investment-bot.onrender.com/health
SELF_PING_MINUTES=10
```

6. **Create Web Service** ← انتظر 2–4 دقائق

## 🔔 أهم إعداد: منع النوم

Render المجاني **ينام بعد 15 دقيقة** بلا طلب. بوت تلغرام يستقبل الطلبات
للخارج (polling) فلا يولّد زيارات واردة → فسينام.

**الحل:** مهمة النبض الذاتي المبنية في البوت ترسل طلباً كل 10 دقائق:

```env
SELF_PING_URL=https://investment-bot.onrender.com/health
SELF_PING_MINUTES=10
```

> ⚠️ **تحقق من الرابط:** افتح `https://investment-bot.onrender.com/health`
> في المتصفح. لو ما اشتغل، الرابط غلط — انسخه من أعلى صفحة الخدمة في Render.
> لو ضبطته غلط، البوت ينام والوضع ما يتحسّنش.

**كيف تعرف أنها شغّالة؟** في السجلات:
```
💓 نبضة ذاتية → 200
✅ مهمة النبض الذاتي مجدولة: كل 10 دقيقة
```

## 🛢️ مشكلة البيانات — اقرأها بجدية

### شنو يصير بالضبط؟

| الحدث | مصير `data/bot.db` |
|---|---|
| كل **نشر** جديد | 🗑️ يُمسح |
| كل **إعادة تشغيل** | 🗑️ يُمسح |
| كل مرة **ينام ويصحى** | 🗑️ يُمسح |
| إعادة تشغيل عشوائية من Render | 🗑️ يُمسح |

Render يقولها صريحة في وثائقه: *"A free web service loses any changes to its
local filesystem, such as uploaded images or **a SQLite database**, every time
it redeploys, restarts or spins down."*

### ✅ الحل على المجاني: نسخة احتياطية دورية

1. أرسل `/id` للبوت في تلغرام → خذ الرقم
2. ضعه في `ADMIN_IDS` ← **Save Changes** (ينتظر إعادة النشر)
3. بعد كل تغيير مهم، أرسل `/backup` للبوت → يحمّل ملف القاعدة
4. احفظ الملف في مكان آمن عندك

> ⚠️ **الاسترجاع يدوي:** للأسف الخطة المجانية ما تعطيك SSH ولا أوامر
> one-off، فما تقدر ترجّع النسخة تلقائياً. يعني أي أموال مسجّلة قبل
> إعادة نشر **تضطر تدوّيها من جديد**. لهذا ما أنصح بالمجاني للاستخدام الحقيقي.

### ✅✅ الحل الصح: Starter + قرص دائم (7.25$/شهر)

1. من صفحة الخدمة ← **Settings** ← **Instance Type** ← **Starter** (7$/شهر)
2. **Disks** ← **Add Disk**:
   - **Name**: `bot-data`
   - **Mount Path**: `/app/data`
   - **Size**: 1 GB (0.25$/شهر)
3. **Save** ← البوت يعيد التشغيل والبيانات تبقى للأبد ✅

> 🎉 **بعد هالخطوة:** الأرصدة تبقى، والعقود تبقى، والنسخ الاحتياطي
> يصير احتياطاً احترازياً مو إنقاذياً.

## 👑 تفعيل لوحة الأدمن

1. من تلغرام أرسل `/id` للبوت → يعطيك رقماً (مثلاً `123456789`)
2. في Render ← **Environment** ← عدّل:
```env
ADMIN_IDS=123456789
```
3. **Save Changes** ← انتظر إعادة النشر
4. أرسل `/admin` في تلغرام 🎛️

## 🔔 إشعارات NOWPayments (للإيداع الفوري)

بعد النشر، Render يعطيك رابطاً عاماً. اضبطه في `.env`:

```env
PUBLIC_URL=https://investment-bot.onrender.com
```

ثم في لوحة NOWPayments ← **Settings ← IPN** ضع:
```
https://investment-bot.onrender.com/webhooks/nowpayments
```

بدونه، الإيداع يعمل عبر المتابعة الدورية (تأخير حتى دقيقة) — يكفي للتجربة.

## 🆘 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| السجلات: `No open ports detected` | التطبيق ما استمعش على المنفذ. **أُصلح في الكود**: صار يقرأ `PORT` تلقائياً — تأكد أن `render.yaml` محدّث |
| `/health` يعطي 404 | الخدمة لسّا بتصحى — انتظر دقيقة |
| `/health` يعطي `Application failed to respond` | تحقق من السجلات؛ غالباً `BOT_TOKEN` ناقص |
| `فشل الاتصال بتلغرام` باستمرار | التوكن خاطئ — راجعه في Environment |
| البوت يرد ببطء شديد (دقيقة) | نام — اضبط `SELF_PING_URL` صح |
| الأرصدة صفّرت بعد النشر | متوقع على المجاني — انظر قسم البيانات أعلاه |
| `Exited with status 1` فوراً | اقرأ السجلات؛ غالباً متغير ناقص |
| البريد/الدفع مطلوب | Render يطلب بطاقة لتخطي حدود المجانية |
