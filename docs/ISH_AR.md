# 🍎 تشغيل البوت من الآيفون عبر iSH

> **الخلاصة أولاً:** البوت لا يستطيع العمل **داخل** iSH — لكن iSH يقدر يكون
> **الطرفية اللي تتحكم بها في سيرفر حقيقي**، والبوت يبقى شغّال 24/7 عليه.
> وهذا أفضل من أي حل محلي: تقفل iSH أو تطفي الهاتف، والبوت ما يتوقفش.

---

## ❓ لماذا لا يعمل البوت داخل iSH نفسه؟

تحققت من السبب الجذري (مش تخمين):

| | |
|---|---|
| **iSH يحاكي معالج 32-bit (i386)** | مو معمارية ARM الحقيقية |
| **محرّك V8 يحتاج تعليمات SSE2** | ومحاكي iSH **لا ينفّذها** |
| **النتيجة** | `node` يسقط فوراً بخطأ `Illegal instruction` — حتى `node --version` |
| **عطل مفتوح منذ 2024** | [iSH#2335](https://github.com/ish-app/ish/issues/2335) + [iSH#90](https://github.com/tbodt/ish/issues/90) |

**جرّبت أتجاوزه بكل الطرق:**

| المحاولة | النتيجة |
|---|---|
| Node قديم من مستودعات Alpine v3.12 | Node 12 — وهذا المشروع يحتاج **22.5+** (لأن `node:sqlite` وُجدت في 22.5) |
| `node --jitless` | يُعطّل WebAssembly أيضاً — وأي بديل لقاعدة البيانات (sql.js) مبني على WASM |
| شوكة `ish-arm64` غير الرسمية | تشغّل Node 22 فعلاً، لكن تحتاج **تثبيت تطبيق خارج App Store** — غير موثوق |

> 📌 **الدروس:** iSH ممتاز في `ssh` و `git` و `curl` (كلها برامج C تعمل داخل المحاكي).
> المشكلة فقط في Node. فنستخدم iSH فيما يتقن، ونشغّل Node على سيرفر حقيقي.

## ✅ الطريق: iSH → SSH → سيرفر لينكس

```
┌──────────────┐         ┌──────────────────────┐         ┌──────────────┐
│  iSH على     │  SSH    │  سيرفر لينكس حقيقي   │         │   تلغرام     │
│  الايفون     │ ──────► │  Node 22 + pm2       │ ──────► │   البوت شغّال│
│  (طرفية فقط) │         │  (البوت يعيش هنا)    │         │   24/7       │
└──────────────┘         └──────────────────────┘         └──────────────┘
        │
        └─── تقفل iSH تماماً → البوت يستمر في العمل ✅
```

### الخطوة 1 — جهّز iSH

افتح iSH ونفّذ:

```bash
apk update
apk add openssh git curl
```

### الخطوة 2 — أنشئ مفتاح SSH داخل iSH

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""
```

اضغط Enter عند أي سؤال. ثم اطبع المفتاح العام:

```bash
cat ~/.ssh/id_ed25519.pub
```

ستظهر سطورة تبدأ بـ `ssh-ed25519 AAAA...` — **انسخها كاملة**، ستحتاجها بالخطوة 4.

> ⚠️ **احتفظ بالمفتاح:** iSH يخزّن ملفاته داخل التطبيق. لو حذفت iOS التطبيق
> يفقد المفتاح. انسخ محتوى `~/.ssh/id_ed25519` واحفظه في مكان آمن عندك.

### الخطوة 3 — أنشئ السيرفر (مجاني دائماً)

**الأفضل: Oracle Cloud — Always Free** (مجاني للأبد، لا ينقطع):

1. من سفاري: [oracle.com/cloud/free](https://www.oracle.com/cloud/free/)
2. سجّل حساباً جديداً (يطلب بطاقة للتحقق — لا يُخصم منها شيء في الخطة المجانية)
3. **Create Instance** → اختر:
   - **Image:** Ubuntu 24.04
   - **Shape:** Ampere A1 (ARM) — الأقوى في المجاني
   - **SSH keys:** الصق المفتاح العام من الخطوة 2
4. انتظر دقيقتين، ثم انسخ **Public IP**

> 💡 **بدائل لو Oracle ما اشتغلت معك:** أي VPS رخيص (Contabo ~5$/سنة، Hetzner ~4$/شهر)،
> أو Google Cloud Shell (مجاني بدون بطاقة — لكن للتجربة فقط، يتوقف عند الخمول).

### الخطوة 4 — اربط iSH بالسيرفر

من iSH:

```bash
ssh ubuntu@Public-IP-هنا
```

أول مرة يسأل `Are you sure...؟` → اكتب `yes` ثم Enter.

لو دخلت وشفت `ubuntu@...` معناها **الاتصال نجح** 🎉

> مشكلة شائعة: لو قال `Permission denied (publickey)` — تأكد أنك نسخت
> المفتاح كاملاً عند إنشاء السيرفر، أو أضفه يدوياً على السيرفر:
> `echo "ssh-ed25519 AAAA..." >> ~/.ssh/authorized_keys`

### الخطوة 5 — شغّل البوت بأمر واحد

**من داخل جلسة SSH على السيرفر** (ليس على الايفون مباشرة):

```bash
curl -fsSL https://raw.githubusercontent.com/TaharBn12/Anvesment/arena/eaf0e7c0-anvesment/scripts/setup.sh -o setup.sh
bash setup.sh
```

السكربت يسألك عن **توكن البوت** — الصقه من @BotFather، ثم ينفّذ كل شيء:

| ما يفعله | |
|---|---|
| 1 | يتحقق من Node ويثبّت 22 إن لزم |
| 2 | يجلب الكود من GitHub |
| 3 | يجهّز ملف `.env` ويحفظ توكنك |
| 4 | `npm install` |
| 5 | يشغّل البوت عبر **pm2** (يبقى شغّال 24/7) |

### الخطوة 6 — تحقق

```bash
pm2 status
```

لازم تشوف:

```
┌────┬─────────────────┬─────────┬────────┬──────┬────────┬──────────┐
│ id │ name            │ mode    │ ↺      │ status  ...
├────┼─────────────────┼─────────┼────────┼──────┼────────┼──────────┤
│ 0  │ investment-bot  │ fork    │ 0      │ online  ...
```

افتح تلغرام → بوتك → `/start` 🎉

### الخطوة 7 — أغلق iSH وانسَ الأمر

**الآن تقدر تقفل iSH وتطفي الشاشة** — البوت يعمل على السيرفر، مش على هاتفك.

لو حبيت ترجع تفقد عليه لاحقاً: افتح iSH → `ssh ubuntu@Public-IP` → `pm2 status`.

## 🛠️ أوامر تحتاجها لاحقاً

كلها من داخل جلسة SSH:

```bash
pm2 status                      # حالة البوت
pm2 logs investment-bot         # السجلات المباشرة (CTRL+C للخروج)
pm2 restart investment-bot      # إعادة تشغيل
bash setup.sh                   # تحديث الكود لأحدث نسخة
nano .env                       # تعديل الإعدادات (CTRL+O حفظ، CTRL+X خروج)
```

## 👑 تفعيل لوحة الأدمن

1. من تلغرام أرسل `/id` لبوتك → يعطيك رقماً (مثلاً `123456789`)
2. على السيرفر:
```bash
nano .env
```
3. عدّل السطر:
```env
ADMIN_IDS=123456789
```
4. `pm2 restart investment-bot`
5. أرسل `/admin` في تلغرام — تظهر لك لوحة التحكم 🎛️

## 🔔 الإيداع التلقائي الفوري (IPN)

البوت يستقبل إشعارات NOWPayments على المنفذ **3000**. لتفعيل الإيداع الفوري:

1. في لوحة NOWPayments → **Settings → IPN** → ضع:
   `http://Public-IP:3000/webhooks/nowpayments`
2. أو اتركه فارغاً — الإيداع يعمل عبر المتابعة الدورية (تأخير دقيقة)

> للإنتاج الحقيقي، ضع `PUBLIC_URL` في `.env` برابط HTTPS (مثل Nginx + دومين).

## 🆘 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `Permission denied (publickey)` | المفتاح العام ما تُضافش صح عند إنشاء السيرفر — أعد إنشاء الـ instance أو أضفه في `~/.ssh/authorized_keys` |
| `Connection timed out` | خطأ في الـ IP، أو المنفذ 22 محجوب — جرّب من شبكة أخرى |
| البوت `online` لكن ما يردش | التوكن خاطئ: `nano .env` وصحّح `BOT_TOKEN`، ثم `pm2 restart investment-bot` |
| `Illegal instruction` في iSH | معناة إنك تحاول تشغّل Node **داخل iSH** — نفّذ الأمر على السيرفر داخل SSH |
| البوت يرسل رسائل مكرّرة | شغّل `pm2 stop investment-bot` على أي نسخة ثانية |
| فقدت الأرصدة بعد إعادة التشغيل | أرسل `/backup` (يحتاج ADMIN_IDS) قبل أي تحديث |
