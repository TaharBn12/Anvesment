# 🤖 لوحة تحكم البوت — على GitHub Pages

موقع ثابت (static) يتكلم مع خادم البوت عبر HTTPS. ما يخزّن ولا يعرف
أسرار — كل شي يمرّ من `ADMIN_API_TOKEN`.

---

## ⚡ التشغيل السريع (3 خطوات)

### 1) اضبط الرمز في خدمتك

في Render / Koyeb → متغيّرات البيئة، أضف:

| المتغيّر | القيمة |
|---|---|
| `ADMIN_API_TOKEN` | رمز طويل عشوائي (انظر أدناه) |
| `ADMIN_API_CORS_ORIGINS` | `https://اسمك.github.io` |

لتوليد رمز قوي — في **PowerShell** على Windows:

```powershell
-join ((1..32) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
```

أو استخدم أي رمز طويل تتذكره. **احفظه** — راح تحتجه للدخول.

> ⚠️ بدون `ADMIN_API_TOKEN` الواجهة **معطّلة بالكامل** — هاذا مقصود
> عشان ما يبقى البوت مكشوف لو نسيت تضبطه.

### 2) فعّل GitHub Pages

1. افتح المستودع على GitHub
2. **Settings** → **Pages** (من القائمة الجانبية)
3. تحت **Source** اختر:
   - **Branch:** `main`
   - **Folder:** `/docs`
4. اضغط **Save**
5. انتظر دقيقة، وراح يظهرلك الرابط:
   `https://اسمك.github.io/Anvesment/`

### 3) افتح اللوحة

ادخل على:

```
https://اسمك.github.io/Anvesment/admin/
```

- **رابط الخدمة:** رابط Render/Koyeb متاعك (مثل `https://xxx.onrender.com`)
- **رمز الدخول:** نفس `ADMIN_API_TOKEN` اللي حطيته

## 🔐 الأمان

| | |
|---|---|
| **الرمز مطلوب** | كل نقطة تحتاج `x-admin-token` — بدونه `401` |
| **معطّل افتراضياً** | `ADMIN_API_TOKEN` فاضي ⇒ ما فيش واجهة أصلاً |
| **CORS** | حدّد `ADMIN_API_CORS_ORIGINS` بعنوان موقعك فقط |
| **الموقع ما يخزّن شي** | الرابط والرمز في `localStorage` متصفحك أنت بس |
| **الإشعارات تروح للمستخدم** | لو حظرت أو عدّلت رصيد، يوصل للمستخدم إشعار في تلغرام |

> 💡 **لو سرقوك الرمز** (مثلاً جهاز مشترك): غيّر `ADMIN_API_TOKEN` في
> متغيّرات البيئة → الرمز القديم يبطل فوراً.

## 🛠 نفس الأوامر من تلغرام

لو ما حبيت تفتح الموقع، كل شي موجود في البوت:

| الأمر | الوظيفة |
|---|---|
| `/admin` | لوحة الأدمن |
| `/ban <معرّف> [السبب]` | حظر مستخدم |
| `/unban <معرّف>` | رفع الحظر |
| `/addbal <معرّف> <مبلغ> [ملاحظة]` | إضافة رصيد (سالب = خصم) |
| `/user <معرّف>` | تفاصيل مستخدم |
| `/backup` | نسخة احتياطية من القاعدة |

مثال:

```
/ban 123456789 سبام
/unban 123456789
/addbal 123456789 50 مكافأة تسجيل
```

## ❓ مشاكل شائعة

**«رمز الدخول غير صحيح»**
→ تأكد أن `ADMIN_API_TOKEN` في الخدمة = اللي كتبته في الموقع.
تأكد أيضاً أنك **أعدت النشر** بعد إضافة المتغيّر.

**«تعذّر الاتصال»**
→ الرابط غلط، أو الخدمة نايمة (Render المجاني ينام بعد 15 دقيقة —
افتح الرابط في المتصفح أول لين يفيق، ثم أعد المحاولة).

**«واجهة الإدارة معطّلة»**
→ `ADMIN_API_TOKEN` ما اضبطتش في متغيّرات البيئة.

**الموقع يفتح لكن الشاشة بيضا**
→ افتح **Console** في المتصفح (F12) وشوف الخطأ. غالباً رابط الخدمة
خاطئ أو ينتهي بشرطة `/` زايدة.

**CORS error في الـ Console**
→ اضبط `ADMIN_API_CORS_ORIGINS` بعنوان موقعك بالضبط، مثل:
`https://taharbn12.github.io` (بدون مسار في الأخير).
