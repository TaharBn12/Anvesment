# ☁️ دليل النشر على Koyeb (الخطة المجانية)

## ⚠️ قبل أن تبدأ: قيودتان في الخطة المجانية وكيف تعاملنا معهما

تحققت من وثائق Koyeb (2026) — الخطة المجانية فيها قيدان مهمان لبوت يحمل أرصدة:

| القيد | الخطر | الحل الذي جهّزته لك في الكود |
|---|---|---|
| 😴 **الخدمة تنام بعد ساعة بلا طلب** | بوت تلغرام يستقبل outward فلا يولّد زيارات → ينام ويتأخر الرد | ✅ **مهمة نبض ذاتي** مدمجة: اضبط `SELF_PING_URL` فقط |
| 💾 **لا قرص دائم** (2GB مؤقت) | قاعدة البيانات (الأرصدة!) تُفقد عند كل تحديث | ✅ **أمر `/backup`** يرسل لك نسخة كاملة في تلغرام |

> 💡 للتشغيل الجدّي بأموال حقيقية لاحقاً: انتقل إلى VPS مجاني دائم ([Oracle Cloud Always Free](DEPLOY_AR.md) أو خطة Koyeb المدفوعة).

---

## 1️⃣ إنشاء الحساب (دقيقتان)

1. من متصفح هاتفك افتح [koyeb.com](https://www.koyeb.com)
2. **Sign up** بحساب GitHub
3. ⚠️ ستحتاج **بطاقة للتحقق** (حجز 29$ يُلغى فوراً) — ثم أنشئ خدمة على الخطة المجانية (Free/Hobby)

## 2️⃣ إنشاء الخدمة

1. من لوحة التحكم: **Create** → **Create Web Service**
2. اختر **GitHub** → مستودع `Anvesment`
3. الفرع: `arena/eaf0e7c0-anvesment`
4. **Builder**: Docker (سيقرأ ملف `Dockerfile` تلقائياً)
5. **Region**: Frankfurt أو Washington
6. **Instance size**: Free
7. **Port**: `3000` (مطابق لإعداد البوت)
8. **Health check**: path = `/health`

## 3️⃣ متغيرات البيئة

في قسم **Environment variables** أضف:

```env
BOT_TOKEN=9068383353:AAEGXAEUpOCy-cdGTGZpy05aADxegQJs3b0
ADMIN_IDS=ضع_معرفك_هنا
NOWPAYMENTS_API_KEY=
NOWPAYMENTS_IPN_SECRET=
CURRENCY=usd
MIN_DEPOSIT=10
MIN_WITHDRAW=5
PAYOUT_HOUR=0
```

> 📝 `ADMIN_IDS`: بعد أول تشغيل أرسل `/id` للبوت في تلغرام وسيعطيك معرّفك، ثم حدّث القيمة.

## 4️⃣ النشر والرابط

1. اضغط **Deploy** وانتظر ~دقيقتين
2. من صفحة الخدمة انسخ الرابط العام (مثل `https://your-app-1234.koyeb.app`)
3. **أعد إضافة متغير بيئي** جديد بالسكر العام:
   ```env
   PUBLIC_URL=https://your-app-1234.koyeb.app
   SELF_PING_URL=https://your-app-1234.koyeb.app/health
   SELF_PING_MINUTES=10
   ```
4. اضغط **Redeploy**

## 5️⃣ التحقق

| الفحص | النتيجة المتوقعة |
|---|---|
| افتح `https://your-app.koyeb.app/health` في المتصفح | `{"ok":true,...}` |
| أرسل `/start` للبوت في تلغرام | رسالة ترحيب + قائمة |
| أرسل `/id` | يعطيك معرّفك (ضعه في ADMIN_IDS) |
| السجلات في Koyeb → Logs | `🚀 البوت يعمل` + `💓 نبضة ذاتية` كل 10 دقائق |

## 6️⃣ إشعارات NOWPayments (للإيداع الفوري)

في لوحة NOWPayments → **Settings → Instant Payment Notifications** ضع:
```
https://your-app-1234.koyeb.app/webhooks/nowpayments
```

بدونه يعمل الإيداع عبر المتابعة الدورية (تأخير دقيقة) — لكن للإنتاج اضبطه.

## 7️⃣ النسخ الاحتياطي (مهم جداً على Koyeb)

بما أن القرص مؤقت، خذ نسخة احتياطية دورية:

1. أرسل `/backup` للبوت (كأدمن)
2. سيصلك **ملف قاعدة البيانات** في محادثة تلغرام
3. احفظه: اضغط عليه → **Save to Downloads** أو أعد توجيهه لـ Saved Messages

**الوتيرة الموصى بها:** مرة يومياً على الأقل. (عند الترقية لخطة مدفوعة أو VPS لاحقاً، يمكنك رفع الملف واستعادة الأرصدة.)

## 🆘 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| البوت لا يرد بعد ساعة | تأكد من `SELF_PING_URL` صحيح و`💓 نبضة ذاتية` في السجلات |
| `Unauthorized` في السجلات | التوكن خاطئ أو مُبطَل (/revoke في BotFather) |
| الإيداع لا يُضاف تلقائياً | اضبط `PUBLIC_URL` ورابط IPN في NOWPayments |
| فقدت الأرصدة بعد تحديث | طبيعي على الخطة المجانية — استعد من آخر ملف `/backup` |
| `❌ فشل الاتصال بتلغرام` | عارض شبكي — البوت يعيد المحاولة تلقائياً |
| الخدمة تتوقف عند البدء | تحقق من السجلات: غالباً متغير بيئي ناقص |
