# 🤖 بوت الاستثمار في العملات الرقمية (تلغرام)

بوت تلغرام كامل للاستثمار في العملات الرقمية، مع **إيداع تلقائي** عبر خدمة [NOWPayments](https://nowpayments.io) (مثل USDT على شبكة TRC20)، و**5 مستويات استثمارية** بربح يومي، ومحفظة خاصة لكل مستخدم، ولوحة تحكم للأدمن.

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| 💰 إيداع تلقائي | المستخدم يختار المبلغ والعملة → يُنشأ له **عنوان دفع فريد** مع رمز QR → يُضاف الرصيد **تلقائياً** بعد تأكيد الشبكة (Webhook + متابعة دورية احتياطية) |
| 🔐 تحقق من الإشعارات | كل إشعار من NOWPayments يُتحقق منه بتوقيع **HMAC-SHA512** قبل احتسابه |
| 📈 5 مستويات استثمار | برونزي/فضي/ذهبي/بلاتيني/VIP — لكل مستوى نسبة ربح يومية ومدة مختلفتان |
| 💸 أرباح يومية تلقائية | مهمة مجدولة تصرف الربح اليومي كل يوم، وتُعيد رأس المال عند اكتمال المدة |
| 💼 محفظة لكل مستخدم | رصيد، إجماليات، سجل عمليات كامل (ledger) |
| 💳 سحب | طلب سحب بعملة وعنوان يختارهما المستخدم → مراجعة الأدمن → دفع تلقائي (إن وُجدت بيانات payouts) أو دفع يدوي |
| 🛠 لوحة أدمن | إحصائيات، طلبات السحب المعلّقة (موافقة/رفض)، رسائل جماعية |
| 🛡️ دقة مالية | كل المبالغ تُحسب بأعداد صحيحة (micro-USD) لتجنّب أخطاء الفواصل العائمة |

## 🚀 التشغيل السريع

```bash
# 1) تثبيت الحزم
npm install

# 2) إعداد المفاتيح
cp .env.example .env
# عدّل .env وأضف BOT_TOKEN و NOWPAYMENTS_API_KEY وغيرها

# 3) التشغيل
npm start
```

ثم افتح تلغرام وأرسل `/start` للبوت.

📖 **الدليل المفصّل خطوة بخطوة** (BotFather، NOWPayments، ngrok، النشر): [`docs/SETUP_AR.md`](docs/SETUP_AR.md)

📱 **تريد التشغيل من الهاتف؟** (Railway مجاني 24/7 أو Termux لأندرويد): [`docs/DEPLOY_AR.md`](docs/DEPLOY_AR.md)

☁️ **النشر على Koyeb المجاني** (دليل كامل + حلول النوم وفقدان البيانات): [`docs/KOYEB_AR.md`](docs/KOYEB_AR.md)

يشغّل مجموعتين من الاختبارات:
- **اختبار الوحدة** (`scripts/smoke-test.js`): 33 فحصاً للدورة الكاملة (إيداع → استثمار → ربح → سحب) ضد قاعدة بيانات مؤقتة.
- **اختبار التكامل الشامل** (`scripts/integration-test.js`): 46 فحصاً يشغّل **البوت الحقيقي** ضد خوادم محاكاة لتلغرام و NOWPayments، ويحاكي مستخدماً يمر بكل الرحلات: `/start` → إيداع مع QR → **إشعار دفع حقيقي عبر Webhook** (مع التحقق من التوقيع ومنع التكرار) → استثمار → صرف ربح يومي → سحب → موافقة الأدمن والدفع التلقائي.

> 💡 الاختبار الشامل كشف أثناء التطوير خطأين حرجين: تعليق `bot.launch()` في وضع polling (كان يمنع بدء مهام الأرباح)، وخلط BigInt مع أرقام SQLite في شاشات المحفظة.

## 💡 كيف يعمل الإيداع التلقائي؟

1. المستخدم يرسل `/start` أو يضغط **💰 إيداع** ويدخل المبلغ بالدولار.
2. يختار العملة (مثل `USDT — TRC20`).
3. البوت ينشئ فاتورة في NOWPayments → يحصل على **عنوان دفع فريد** + المبلغ المطلوب بالعملة الرقمية.
4. يرسل للمستخدم العنوان + رمز QR + رقم الفاتورة.
5. عندما يدفع المستخدم:
   - **الطريق الأساسي:** NOWPayments يرسل إشعاراً فورياً (IPN) إلى خادمك → يُتحقق من التوقيع → يُضاف الرصيد تلقائياً.
   - **الطريق الاحتياطي:** مهمة دورية تتأكد من حالة كل فاتورة معلّقة كل دقيقة.
6. يصل المستخدم إشعار تأكيد، ويمكنه الاستثمار فوراً.

## ⚠️ ملاحظات مهمة

- **الأرباح افتراضية:** هذا البوت يسجّل أرباحاً تُدار من قاعدة البيانات. كن واعياً للالتزامات القانونية في بلدك قبل التشغيل الفعلي.
- **الأمان:** لا ترفع ملف `.env` إلى Git (مستثنى مسبقاً في `.gitignore`). اضبط `NOWPAYMENTS_IPN_SECRET` دائماً في الإنتاج.
- **النشر:** شغّل البوت خلف HTTPS (مثل nginx + دومين) حتى تعمل إشعارات NOWPayments، أو استخدم `ngrok` أثناء التطوير.
